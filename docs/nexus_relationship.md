# Nexus Relationship — Genova Operator

## Philosophy: "Genova Nexus thinks, Genova Operator acts."

Genova Nexus serves as the high-level intelligent layer responsible for understanding user requests, creating operational plans, and orchestrating work across software projects.

Genova Operator acts as the low-level operational backbone that:
- Inspects target projects (`GeneFusionAI`, `Clarify`, etc.)
- Manages execution environments and python runtimes
- Runs background tasks and monitors CPU/GPU/memory resources
- Automates recurring jobs, pipelines, and ML experiments
- Provides structured status and result objects back to Genova Nexus
